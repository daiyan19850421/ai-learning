## 约束
- 依据[0001-targets.jpg](0001-targets.jpg)制定学习计划
- 不考虑本上层目录的内容，只看本目录和所有子目录的内容
- 一小步一小步地来，不把长期所有计划都给出来
- 学习方式：给出学习内容 -> 我记笔记 -> 自己总结学习结果 -> 询问下一步学习内容
- 近期目标：学懂如何深入使用 AI
- 中期目标：给软件研发团队提效
- 最终目标：利用 Agent 为正规公司赋能
- 给出新的学习内容前先检查以往的内容和路线是否和[0001-targets.jpg](0001-targets.jpg)已经出现偏差
- 新的学习内容以以`递增序号-内容.md`生成新的文档
- 学习内容必须有相关的 3 至 5 篇权威、受认可度高的文档链接可供阅读
